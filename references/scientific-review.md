# 科学事实与表述风险审查

> 用于科普、科技、历史与数据解释类视频。目标是让错误、过度简化和证据不足在写代码前暴露，而不是让语言模型凭流畅度判断事实真假。

## 1. 必须经过独立审查

第 2 步先审查原始知识主张，第 5 步再审查叙事改写与逐镜视觉隐含主张；第 6 步 Review 通过前完成复核，才能进入第 7 步视觉实现：

1. **提取可核验主张**：逐镜列出涉及数字、因果、机制、时间、空间、比较、范围与绝对化措辞的句子。
2. **标记风险**：`low | medium | high`。涉及爆炸/核技术、医学、法律、金融、重大历史争议、精确数量级、因果机制时默认至少 medium。
3. **核验来源**：优先原始研究、政府/大学/专业机构、标准或高质量综述；记录来源、发布日期/版本、支持哪一条主张。仅凭搜索摘要或二手转述不能把高风险主张标记为已核验。
4. **改写**：区分事实、模型解释、比喻和不确定性。限定适用条件与范围；不要把示意动画当作实测数据。
5. **复核**：改写后的句子再次与来源对照，检查有没有把局部事实扩大成普遍规律。
6. **放行**：未解决的高风险主张不得静默进入成片；要么补证据、改写为明确不确定性，要么删除，并在 review 中说明。

## 2. 每条主张的审查表

| 字段 | 内容 |
|---|---|
| sceneId | 第 2 步先用 claimId 定位原始主张，第 5 步补对应镜头编号 |
| claim | 可独立判断真假的最小主张 |
| claimType | 数字 / 因果 / 机制 / 比较 / 时间 / 空间 / 绝对化 / 其他 |
| risk | low / medium / high |
| evidence | 来源标题、链接、作者/机构、日期或版本 |
| support | 直接支持 / 部分支持 / 不支持 / 来源冲突 |
| issue | 范围扩大、术语混用、因果过度简化、缺条件、数字不精确等 |
| revision | 修订后文案，或明确待核验项 |
| status | `pass | revise | needs_verification | human_review` |

状态定义：
- `pass`：证据与措辞匹配，可进入制作。
- `revise`：已发现可修正问题，修订后必须复核。
- `needs_verification`：证据不足，禁止当作已证实事实。
- `human_review`：来源冲突、专业判断或高风险内容需人工决定。

## 3. 高风险措辞触发器

以下词语只触发检查，不自动证明句子错误：

- 绝对化：一定、必然、完全、从不、所有、唯一、瞬间、立刻。
- 过度因果：因为 A，所以必然 B；把复杂过程缩成单一原因。
- 无范围数字：最高、最低、首次、最大、精确到小数但无来源。
- 概念混用：速度/冲击波速度/物质流速；温度/能量/亮度；相关性/因果性；当量/火球尺度/热辐射。
- 比较泛化：把一个案例扩展到某类技术、某一历史时期或所有情况。
- 拟人/比喻：把比喻误读为真实机制，或动画画面暗示了旁白没有说过的结论。

## 4. 科学动画的额外要求

- 图形的运动、尺寸和速度若不是数据驱动，应标为“示意”，不要呈现成精确测量。
- 颜色仅代表图例约定，不自动等于温度、危险等级或真实材料属性。
- 流线/粒子需对应已核验的运动关系；无数据时不模拟“精确流场”。
- 夸张、压缩时间或省略中间步骤时，旁白/画面应避免误导；必要时加“示意图”“过程已压缩”等提示。
- 真实数字要与字幕、图表、旁白和画面标注一致；同一概念全片单位统一。
- 复杂机制优先呈现因果链与关键状态，不为视觉冲击捏造细节。

## 5. 进入视觉制作的放行条件

- [ ] 所有关键主张已列出；不是只审查标题和结论。
- [ ] 数字、因果、机制、比较与绝对化表达均有适配来源或已限定措辞。
- [ ] 高风险主张没有 `needs_verification` 残留。
- [ ] `human_review` 项已由操作者明确决定如何处理。
- [ ] 动画示意与事实主张一致；无法精确表达的地方已明确简化边界。
- [ ] 科学审查表第 2 步写入 `制作过程/知识解析与证据.md`，第 5 步复核改写与画面隐含主张后汇入 `制作过程/视频方案审阅稿.md`，不另建审查文件；后续修改文稿后重新核验受影响主张。

规则扫描只能发现疑点，不能自动判定科学真伪。模型不得编造来源、DOI、论文题目或机构背书。
