# 色板系统

> 本文是**颜色选择的唯一权威**。字体角色、字号、字幕条规则一律见 [short-video-typography.md](short-video-typography.md)。
> **默认色板：`paper`（纸本）**——未明确指定题材/参考片时，一律使用 `paper`。

---

## 一、色板：一支片一套色

镜头表前的「色板」一行，从这里挑一套写名字，或者按文末的规则自己定 3–6 个色值。所有参数化片段的 spec 写同一个 `"theme"`，scenes 里也只用这几个色（加减明暗、透明度可以，别引入新色相）。

### 1.1 先说禁区

**蓝紫渐变底、深紫星空底、霓虹青紫光效、紫色毛玻璃**：作者原话「我们需要规避下蓝、紫渐变的垃圾配色，这种非常 ai slop」。这几样是 AI 做动画最常落进去的默认色，观众一眼就读成「AI 做的」。

`deliver.py` 会量出来：一帧里 30% 以上是蓝紫（色相 225°–300°、饱和度 ≥0.30）就算蓝紫帧，蓝紫帧占全片 30% 以上红灯，不出片。题材本身就要蓝紫时（用户点名的赛博朋克紫、梵高星月夜这类风格画面），交付时加 `--allow-blue-purple "理由"`，降为黄灯，理由写进交付说明的事实段。

海军蓝平涂（色相约 210°，见下面 `navy`）不在禁区里：它是有意图的单一底色，不是渐变也不发光。

### 1.2 八套现成色板

每套 6 个键：`bg` 底、`surface` 卡片／纸／面板、`ink` 主字、`sub` 次字和细线、`accent` 主强调、`accent2` 副强调。片段 spec 里写 `"theme": "wood"`，或者写成对象 `{"name": "wood", "accent": "#B8452A"}` 只改其中一个键。

| 名字 | 适合 | bg | surface | ink | sub | accent | accent2 |
|---|---|---|---|---|---|---|---|
| `paper` 纸本 · 默认 | 人文、历史、读书、解释一个道理 | #F3EDE2 | #FBF8F2 | #1B1A17 | #6B655B | #C8402F | #2F5D62 |

### 1.3 styleMode 与色板对应

选好 `styleMode`（见 `visual-system.md` 决策树）后，按下表选色板。**未明确指定时一律用 `paper`**。

| styleMode | 推荐色板 | 备注 |
|---|---|---|
| `tech-mint` | `ink` / `navy` / 专属深空色板（见下方 2.1） | 深空科技感，暗底 |
| `kurzgesagt` | `ink` / `navy` / 专属高饱和撞色（见下方 2.3） | 深底 + 高饱和撞色，全片 ≤ 5~6 色 |
| `vox` | `ink` / `navy` / 专属近黑底（见下方 2.4） | 克制冷调，图表驱动 |
| `vox-light` | `paper`（默认）/ `snow` / 专属浅底方案（见下方 2.5） | 浅底清爽，适合视频号 |
| `doodle-note` | `paper`（默认）/ 专属薄荷淡青纸底（见下方 2.6） | 浅色纸底，纯黑单线 |

> 色板与 styleMode 是**正交关系**：styleMode 决定叙事手段，色板决定具体颜色。同一 styleMode 下可按题材切色板，但全片只用一套。

## 二、各 styleMode 专属色板

### 2.1 `tech-mint` · 主色组（深空 × 薄荷绿）

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景深底 | `#0a0818` / 径向 `#1a1240→#0d0926→#0a0818` | 整片底色 |
| 主强调色 | `#4be69b`（薄荷绿） | 关键词高亮、强调线、标题点睛字 |
| 副强调色 | `#9cffd1`（浅薄荷） | 副线、装饰星点、引语 |
| 文字主色 | `#e8fff3` / `#fff` | 标题、正文 |
| 警示色 | `#fbbf24` / `#ff7a3d` / `#f472b6` | 翻车 / ≠ / 对比侧 |
| 工程师侧 | `#60a5fa` | 二元对比左侧 |
| 用户侧 | `#f472b6` | 二元对比右侧 |

#### 2.2 Effect 背景色方案（仅 `tech-mint`，脚本确认后询问，默认方案一）

| 方案 | 名称 | 渐变（top→bottom） | 适用场景 |
|---|---|---|---|
| 方案一（默认） | 深海蓝黑 | `#0d0d1a → #1a1a3a` | 通用科技/AI类，稳重 |
| 方案二 | 深紫星云 | `#0e0618 → #1d0a35` | 人文/文化/哲学类，神秘 |
| 方案三 | 墨绿深夜 | `#050f0a → #0a1f14` | 自然/环保/成长类，沉静 |
| 方案四 | 暖棕烛光 | `#120a04 → #1f1008` | 故事/创作/历史类，温暖 |

提问格式：

> "脚本已确认，请选择 Effect 背景色方案（默认方案一）：
> - 方案一·深海蓝黑：`#0d0d1a → #1a1a3a`（稳重科技感，推荐）
> - 方案二·深紫星云：`#0e0618 → #1d0a35`（神秘感强，适合人文/文化主题）
> - 方案三·墨绿深夜：`#050f0a → #0a1f14`（自然质感，薄荷绿强调色更突出）
> - 方案四·暖棕烛光：`#120a04 → #1f1008`（差异化最强，适合故事/创作主题）"

实现：`<AbsoluteFill style={{ background: "linear-gradient(180deg, <顶> 0%, <底> 100%)" }}>`

### 2.3 `kurzgesagt` · 高饱和撞色

深底 + **高饱和撞色**，全片色板 ≤ 5~6 色（骚橙 `#ff8c42` / 亮青 `#2ec4b6` / 洋红 `#e94f9c` / 明黄 `#ffd23f` / 亮蓝 `#4cc9f0`）。背景单一深色块（深藏蓝 `#1a2b4a` / 深青 `#0f2e2e` / 深洋红棕 `#2e1a2e` 任选一，**全片一个底色**）。

### 2.4 `vox` · 克制冷调

近黑 `#0b0b0d` / 深灰 `#141416` 纯底，克制冷调 + **单一强调色标注**（Vox 黄 `#ffd400` / 白 `#ffffff`），红圈 `#ff3b30` 划重点。

### 2.5 `vox-light` · 浅底方案（纯色实底，无渐变）

微信视频号在白色信息流里，近黑底会显得沉闷压抑；浅底更清爽、字幕可读性更好。纯色实底，不做渐变。

| 方案 | 名称 | 背景底 | 卡片 / 描边 | 主强调 | 文字主色 | 适用场景 |
|---|---|---|---|---|---|---|
| 浅一（默认） | 清爽薄荷 | `#F4F8F7` | `#FFFFFF` / `#C9D8D3` | `#0F9D78` | `#17312B` | 技术科普/AI/工程，清爽专业（实测：ep5） |
| 浅二 | 暖米纸 | `#F7F4EE` | `#FFFFFF` / `#DCD5C6` | `#C8872B` | `#2C2418` | 人文/阅读/成长，温润 |
| 浅三 | 冷调石灰 | `#F2F4F7` | `#FFFFFF` / `#D2D8E0` | `#2F6FE0` | `#1B2430` | 商业/数据/分析，中性克制 |

浅一（默认）完整角色表：

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景底 | `#F4F8F7`（薄荷灰） | 整片纯底，**无渐变无星空** |
| 次级底 | `#E7F0ED` | 低强度 pill、空槽、未填充条 |
| 卡片底 | `#FFFFFF` | 所有信息卡、图表容器 |
| 描边 | `#C9D8D3` | 卡片边框、分隔线、未激活元素 |
| 主强调色 | `#0F9D78`（翠绿） | 关键词、激活态、标注线、进度指示 |
| 文字主色 | `#17312B`（深墨绿） | 标题、结论、正文 |
| 次级文字 | `#5F746E` | 副标、说明、未激活项 |
| 警示色 | `#E85D5D`（珊瑚红） | 「不足」「墙」「空置」类负面判断，**全片克制使用** |
| 反白文字 | `#FFFFFF` | 翠绿实心 pill / 圆圈内的字 |

提问格式（选浅底模式时）：

> "请选择浅底背景色方案（默认浅一）：
> - 浅一·清爽薄荷：底 `#F4F8F7` + 翠绿 `#0F9D78`（技术科普推荐）
> - 浅二·暖米纸：底 `#F7F4EE` + 赭黄 `#C8872B`（人文/阅读）
> - 浅三·冷调石灰：底 `#F2F4F7` + 蓝 `#2F6FE0`（商业/数据）"

实现：`<AbsoluteFill style={{ background: "#F4F8F7" }}>`，并把色板集中到 `src/effects/palette.ts` 单点维护，换方案只改一处。

#### 浅底专属约束（与深底模式相反，易踩）

- 字幕改**深色**（文字主色），加浅色 textShadow（`0 2px 8px rgba(255,255,255,0.92)`）压住图形，不要沿用深底模式的浅色字（字号与字体见 [short-video-typography.md §4](short-video-typography.md)）
- 整片渐隐遮罩必须**与底色同色**（如浅一用 `#F4F8F7`），不能用黑色，否则片尾会「压黑」破坏调性
- 禁用一切发光滤镜（浅底发光会糊成灰雾）；层级靠**描边 + 白卡 + 字重**拉开，不靠光
- 警示红只给真正的负面判断，不要用来做常规强调，否则浅底上视觉噪音极强

### 2.6 `doodle-note` · 手绘纸底

浅色纸底纯色（默认薄荷淡青 `#DEF6F2`），全片不变，**禁渐变/星空/粒子**。线条纯黑 `#1a1a1a` 单线，等线宽 3~4px，圆头圆角，**无填色无阴影**。

## 三、自己定一套

- **3–6 个色**：一个底，一个面，一个主字，一个次字，一两个强调。强调色一镜里只用来指一个东西。
- **底色先定**：亮底（纸、雪、木）还是暗底（墨、海军、黑板），全片不在亮暗之间来回跳。
- **色值避开蓝紫区**：色相 225°–300° 且饱和度 ≥0.30 的色不当底、不大面积用。`storyboard_lint` 查色板里的色值，落在这一区红灯。
- **不用渐变底**，不加霓虹外发光。要层次就用纸纹、颗粒、明暗两层平涂。
- 有真实素材（截图、照片）时，从素材里取一两个色当强调，底色仍然用这一套。

## 四、自检

交付前把抽帧排成一排看：

1. 底色是不是从头到尾同一个亮度区间？
2. 强调色是不是只有那一两个？
3. 有没有哪一镜突然冒出白底柱状图、紫色星空、霓虹边框这种「别的片子的颜色」？

有，就把那一镜按色板重画。
