# 色板：一支片一套色

本文件是新项目全局颜色的唯一来源。第 4 步锁定色板，第 5 步把名称与六个 HEX 值写入 `制作过程/视频制作方案.json` 和 `制作过程/视频方案审阅稿.md`；第 7 步将其落到 `src/effects/palette.ts`，并同步到 `scenes.json`。Scene、Effect、字幕、图表、连线、片尾遮罩和封面都引用同一套颜色，不让模型逐镜配色。

## 默认设置：paper 暖浅底

未收到操作者明确的主题、品牌或参考片要求时，使用 `paper` 色板，兼容字段 `styleMode: "vox-light"`。默认不询问配色，不根据题材擅自切换深底。

暖浅底用于知识讲解、流程、对照及人文内容：暖纸底、深墨文字、红色主强调、青绿副强调；纯色平涂，不用纯白大面积背景、渐变、星空或发光。浅底与深底没有天然的传播优劣，默认选择服务本 Skill 的知识解释定位，不宣称已验证播放效果。

操作者明确要求科技氛围或深色观感时，可整片改用 `ink` 或 `navy`；实验、医疗等清爽参考可采用 `snow`。切换必须统一更新全局主题并重新 Review，不能镜头间反复切换亮暗。

```ts
export const palette = {
  bg: "#F3EDE2",
  surface: "#FBF8F2",
  ink: "#1B1A17",
  sub: "#6B655B",
  accent: "#C8402F",
  accent2: "#2F5D62",
} as const;

export const semanticColors = {
  success: palette.accent2,
  warning: palette.accent,
  error: palette.accent,
  chartPrimary: palette.accent,
  chartSecondary: palette.accent2,
  border: palette.sub,
  mask: palette.bg,
} as const;
```

- 警告和错误默认共用主强调色，通过图形、符号与文字区分，不只靠颜色区分状态。
- 未激活态、网格线、描边、阴影可调整已有色的透明度；新派生色必须在 palette.ts 集中计算并记录，不引入新色相。
- 多系列图表超过两种颜色时，优先用线型、纹理或拆图区分，不能临时添加随机颜色。
- 强调色实底上的文字必须检查对比度，按已有色选择可读字色，不能无条件使用白字；默认徽章使用 surface 底与 ink 字。
- 真实图片不强行改色；其容器、标注、连线、边框与视频主题统一。
- 旧项目保持其已批准的主题；以下默认只应用于新项目。

## 先说禁区

**蓝紫渐变底、深紫星空底、霓虹青紫光效、紫色毛玻璃**：作者原话「我们需要规避下蓝、紫渐变的垃圾配色，这种非常ai slop」。这几样是 AI 做动画最常落进去的默认色，观众一眼就读成「AI 做的」。

第 5 步检查方案中的实际色值，第 10 步由人工检查抽帧。大面积蓝紫（色相 225°–300°、饱和度 ≥0.30）作为重点风险排查；题材确需使用时，先取得操作者确认并把理由写入主题覆盖记录。本工程不依赖外部 `deliver.py` 或 `--allow-blue-purple`，也不声称已执行像素占比检测。

海军蓝平涂（色相约 210°，见下面 navy）不在禁区里：它是有意图的单一底色，不是渐变也不发光。

## 八套现成色板

每套 6 个键：`bg` 底、`surface` 卡片／纸／面板、`ink` 主字、`sub` 次字和细线、`accent` 主强调、`accent2` 副强调。项目主题配置记录色板名与六键实际值，不仅写一个名称。自定义覆盖须由操作者明确要求并进入 Review。

## 自己定一套

- 3–6 个色：一个底，一个面，一个主字，一个次字，一两个强调。强调色一镜里只用来指一个东西。
- 底色先定：亮底（纸、雪、木）还是暗底（墨、海军、黑板），全片不在亮暗之间来回跳。
- 色值避开蓝紫区：色相 225°–300° 且饱和度 ≥0.30 的色不当底、不大面积用。第 5 步静态检查色板值，例外必须记录操作者批准的理由。
- 不用渐变底，不加霓虹外发光。要层次就用纸纹、颗粒、明暗两层平涂。
- 有真实素材（截图、照片）时，从素材里取一两个色当强调，底色仍然用这一套。

## 自检

交付前把抽帧排成一排看：底色是不是从头到尾同一个亮度区间，强调色是不是只有那一两个，有没有哪一镜突然冒出白底柱状图、紫色星空、霓虹边框这种「别的片子的颜色」。有，就把那一镜按色板重画。
