# 视觉系统参考

> 本文只负责**选风格**（`styleMode` / 版面 / 动效 / 字幕结构）。
> 具体色值与色板切换见 [color-palette.md](color-palette.md)（默认色板 `paper`）；**字体角色、字号、字幕条规则见 [short-video-typography.md](short-video-typography.md)**，本文不再重复色值与字号。

## 视觉风格模式（styleMode · 四选一，Step2 样式确认时锁定 · 见下方决策树）

整片必须先选定一套 `styleMode`，写入 `scenes.json` 顶层，全片统一，不得逐镜混搭底色/字体逻辑（但 `shot_type` 可逐镜路由，见 SKILL.md）。四套模式对应四种叙事范式：

| styleMode | 参照 | 叙事逻辑 | 适配题材 | 底层背景 |
|---|---|---|---|---|
| `tech-mint` | 原创深空薄荷 | 画面氛围驱动，星空科技感 | AI/技术/工程/互联网黑话 | StarfieldDrift 星空 + 径向渐变 |
| `kurzgesagt` （默认）| Kurzgesagt | **一镜一概念**，画面主导、旁白配画 | 科普/原理/抽象概念/系统机制 | 纯色块底，**禁用 StarfieldDrift/渐变/粒子** |
| `vox` | Vox·Explained | **口播驱动**，图表即主体、旁白带读 | 分析/观点/数据/行业内幕/复盘 | 纯色底，档案质感，图表铺满 |
| `doodle-note` | 手绘读书笔记 | **逐笔绘制**，单色线稿 + 常驻栏目标题 | 读书解说/成长/职场/价值观/金句 | 浅色纸底，纯黑单线，**禁渐变/星空/粒子** |

### 风格选择决策树（**必须按此顺序判定，禁止凭美学选**）

选错风格的代价不是"不好看"，是**叙事逻辑和画面手段对不上**（例：用生图画数据→数字糊；用信息图画氛围→像 PPT）。按四问依次排除：

```
① 画面里有没有「精确的字和数」（占比/曲线/时间线/多项对比）？
   有 → vox（图表即主体，旁白带读；图表必须代码精绘或信息图，禁生图）
   没有 ↓

② 是「讲机制原理」还是「讲观点态度」？
   机制/原理/系统（回答"为什么会这样"）→ kurzgesagt（一镜一概念，画面主导）
   观点/态度/认知（回答"我怎么看"）    → ↓

③ 观点的载体是「技术感」还是「人味」？
   技术/工程/AI/互联网黑话 → tech-mint
   读书/成长/职场/价值观   → doodle-note
   ⚠️ 情绪共鸣类题材套 tech-mint = 星空+蓝紫渐变，AI slop 高发区

④ 最后校验：素材形态 + 一致性风险
   无图素材，且需要 20~40 张同风格画面 → 代码画（doodle-note / kurzgesagt），一致性 100%
   有实拍/截图/真实数据                → vox / tech-mint
```

**命中信号 vs 反信号（用于二次确认）**

| styleMode | 命中信号 | 反信号（选了就翻车） |
|---|---|---|
| `vox` | 有曲线/占比/时间线，旁白在"带读"一张图 | 全是抽象概念、没有一个数 → 空图表 |
| `vox-light` | 同 `vox`，且主投微信视频号、想要清爽不压抑的观感 | 需要影院感/悬疑感/夜间质感 → 浅底会显得像 PPT |
| `kurzgesagt` | "它是怎么运作的"，可拆成一镜一概念 | 观点密集、一镜要塞三层意思 |
| `tech-mint` | 技术选型、架构、工程踩坑 | 情绪/共鸣类题材 → AI slop |
| `doodle-note` | 读书解说、金句、认知台阶，需要亲和力 | 需要精确数据、真实质感、炫技视觉 |

> **两条覆盖规则**：
> 1. **操作者给了参考片 → 风格由参考片决定**，不走决策树；此时只需判定"该风格能否跑通"（素材是否够、一致性风险是否可控）。
> 2. **决策树结论必须写进 `draft-review.md` 的样式确认表**，逐问给出结论，便于操作者反驳。

> **风格选择的本质权衡**：代码画 = 一致性 ★★★★★ / 表现力受限（复杂隐喻画不出来，须简化或换喻）；AI 生图 = 表现力 ★★★★★ / 一致性靠 anchor + seed + 后处理死守。**先定一致性下限，再谈表现力。**

### 模式一 · `tech-mint`（深空薄荷）

画面氛围驱动，星空科技感。色板见 [color-palette.md §2.1](color-palette.md)（深空薄荷主色组）与 §2.2（Effect 背景色方案）。适合科技调性，但**注意**：星空粒子 + 蓝紫渐变正是通用 AI 审美（AI slop）的高发区，若题材偏科普/观点，优先切 `kurzgesagt` / `vox`。

### 模式二 · `kurzgesagt`（扁平矢量科普，默认）

| 项目 | 规范 |
|---|---|
| 色板 | 见 [color-palette.md §2.3](color-palette.md)：深底 + **高饱和撞色**，全片色板 ≤ 5~6 色，**全片一个底色** |
| 图形 | **扁平矢量、纯色块**，圆角图标，拟物化小图标；**无渐变、无阴影、无质感、无粒子、无发光** |
| 信息密度 | **一镜一概念**：每个 scene 只讲一件事，画面只放一个核心图形 + 极简标注，绝不一图堆三层 |
| 动效 | 2D 平移/缩放/整体淡入，元素依次弹入（easeOutBack 轻微回弹），节奏快 |
| 禁用 | ❌ StarfieldDrift ❌ 任何渐变 ❌ 漂浮粒子 ❌ 玻璃拟态 ❌ 阴影/发光滤镜 |

> `kurzgesagt` 模式下 Composition 入口**不挂 StarfieldDrift**，Scene 直接用纯色 AbsoluteFill 打底。

### 模式三 · `vox`（图表驱动解释）

| 项目 | 规范 |
|---|---|
| 色板 | 见 [color-palette.md §2.4](color-palette.md)：克制冷调 + **单一强调色标注** |
| 画面主体 | **图表即主角**：一条曲线/一张地图/一组柱状铺满全屏，旁白带着一段段读；画面为口播做证据 |
| 标注 | **标注线、箭头、圈红、下划线**，像老师在幻灯片上划重点，逐帧点亮 |
| 叙事结构 | **抛问题 → 给背景 → 层层推进 → 落一个判断**（对应 Step2 草稿的 R·共鸣 + 节奏卡点） |
| 音画关系 | 严格口播驱动：**S4 配音先定时长**，图表标注节奏跟随旁白（本 skill sync-durations 精对齐天然契合） |
| 禁用 | ❌ 花哨转场 ❌ 蓝紫渐变 ❌ 粒子 ❌ 图表用生图模型画（数字必糊，须用信息图/Remotion 精绘） |

#### `vox` 的浅底变体 · `vox-light`（清爽浅底）

微信视频号在白色信息流里，近黑底会显得沉闷压抑；浅底更清爽、字幕可读性更好。`vox` 的全部叙事与标注规范不变，只替换色板为浅底方案（见 [color-palette.md §2.5](color-palette.md)，默认浅一·清爽薄荷）。实测项目：`大模型推理原理介绍/ep5`。

**浅底专属约束（与深底模式相反，易踩）**

- 字幕改用**深色字** + 浅色 textShadow 压住图形（见 short-video-typography.md §4），不要沿用深底模式的浅色字
- 整片渐隐遮罩必须**与底色同色**，不能用黑色，否则片尾会「压黑」破坏调性
- 禁用一切发光滤镜（浅底发光会糊成灰雾）；层级靠**描边 + 白卡 + 字重**拉开，不靠光
- 警示色只给真正的负面判断，不要用来做常规强调，否则浅底上视觉噪音极强

### 模式四 · `doodle-note`（手绘读书笔记）

| 项目 | 规范 |
|---|---|
| 色板 | 见 [color-palette.md §2.6](color-palette.md)：浅色纸底纯色，全片不变，**禁渐变/星空/粒子** |
| 线条 | 纯黑单线，等线宽 3~4px，圆头圆角，**无填色无阴影** |
| 手绘感 | path 端点抖动 + 中段弓形偏移（确定性伪随机，同 seed 同结果）；**小半径圆的抖动幅度须随半径收敛**，否则圆会变成多边形 |
| 绘制动效 | `pathLength=1` + `strokeDashoffset` 做**逐笔绘制**，元素按语义顺序错峰画出（比擦除/滑动更贴手绘笔记） |
| 版式 | 三段固定：顶部常驻栏目标题 / 中部插画 `contain` / 底部字幕。**此模式下"顶部常驻标题"是版式特征，不受"❌ 顶部 eyebrow"否定项约束** |
| 防冻结 | 插画画完后须有**纸面呼吸**（极缓 translate/scale/±0.12° rotate），否则长镜后半段完全静止 |
| 素材来源 | 优先**代码手绘 SVG**（一致性 100%、可逐像素改）；复杂有机轮廓用不规则平滑闭合形，别用多边形硬凑 |
| 已知边界 | 复杂隐喻（提灯、乐器、特定器物）代码画不出来，**读不出语义就删掉换喻**，不要留着凑数 |

### AI slop 红线（四模式通用）

无论哪套模式，凡是「生图/画面」环节，一律避免：**蓝紫渐变、玻璃拟态、漂浮粒子、无意义光晕、赛博霓虹堆砌**。生图提示词固定加负向约束：`flat design, solid color blocks, no gradient, no glow, no particles, no glassmorphism`。色值禁区细则见 [color-palette.md §1.1](color-palette.md)。

## 版面安全区（关键约束）

```
┌─────────────────┐  y=0
│   留白           │  0–150
├─────────────────┤
│  上方视觉区      │  top:150, left/right:40, height:1210
│  (Effect/图)    │  objectFit: contain，禁止 cover
├─────────────────┤  y=1360
│  字幕带         │  top:1440, left/right:56, bottom=220(锁定)
├─────────────────┤  y=1700
│  平台安全区      │  1700–1920 禁止任何内容
└─────────────────┘  y=1920
```

## 装饰要素

- **StarfieldDrift**（**仅 `tech-mint`**）：全片底层，80星点飘落+闪烁，金色占1/11，透视网格，详见 references/code-templates.md §1。`kurzgesagt` / `vox` 模式**禁用**此组件
- **透视网格**（仅 `tech-mint`）：细线汇聚中心，opacity 0.06–0.08
- **强调横线**：渐变 + feGaussianBlur 发光（`kurzgesagt` 改用纯色块实线，无发光）
- **大字发光**：stdDeviation ≈ 14–18；**小元素发光**：stdDeviation ≈ 6–10（`kurzgesagt`/`vox` 禁用发光滤镜）

> 以上装饰的具体色值见 [color-palette.md](color-palette.md)。

## Effect 组件规范

- **底色按 styleMode 决定**：`tech-mint` 下 Effect AbsoluteFill 必须 `background: "transparent"`（否则遮住 StarfieldDrift）；`kurzgesagt`/`vox` 下无星空层，Effect 直接用该模式的纯色底（色值见 color-palette.md）
- 禁用 3D rotateY 翻页——竖屏透视变形，改用2D平移/缩放/淡入
- 字号见 [short-video-typography.md](short-video-typography.md)
- 进入时间用绝对帧数，不用百分比
- prop 接口：`{ frame, fps, durationInFrames, scene }`，**必须完整解构**，不得只解构 `frame` 丢掉 `scene`
- **容器与内容必须共用同一 opacity 入场**：背景色块（有 `background`/`borderRadius` 的容器 div）和其子元素（文字/图标/进度条填充）**必须共用同一个 opacity 动画变量**，不允许容器先于内容出现——否则会出现「先渲染一排空色块/空底轨，内容才逐步浮现」的视觉 bug。正确做法：opacity 加在最外层容器上，而非只加在内层文字上

## 字幕系统

字幕字号与字体见 [short-video-typography.md §4](short-video-typography.md)，配色见 [color-palette.md](color-palette.md)。本文只约束**排版与节奏结构**：

- **每次只显示一行**，任何时刻屏幕上只有一条字幕，旧行淡出→GAP→新行淡入
- **每行不超过 13 个视觉字符**（中文字符计1，英文/数字计0.55），确保不折行
- FADE_IN=10帧，FADE_OUT=10帧，GAP=8帧
- **三级切割顺序**（`chunkText` 算法）：
  1. 先按强标点切（`。？！；…`）
  2. 超过 13 字的段再按逗号/顿号切（`，、,`）
  3. 仍超过 13 字的段按字符数机械截断
- 切割后每块按 `visualLen` 比例分配显示时间

## 封面规范

- V1+V2 两版，1080×1440
- 两版都必须：**问句大标题** + **格式化核心内容**（编号/色块/对比，禁纯文字段落）
- V2 背景与视频首帧一致，无跳变
- 标题.txt：问句≤16字符（以 SKILL.md Step6 为准）；描述.txt：内容摘要≤1000字符，结尾带 #话题标签

## narration vs subtitle 规则

- 两者内容必须完全一致，仅允许英文术语→中文等价物替换（发音修复）
- subtitle 保留英文原词；narration 替换为中文读音友好的等价词
- TTS 读 `narration ?? subtitle`
