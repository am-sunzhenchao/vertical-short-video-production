# 视觉系统参考

## 视觉规划原则：知识表达优先，全局身份统一

先明确每个知识点让观众看懂什么，再选择 `visualGrammar`、单镜 `shotLang`、`motionPlan` 与已有 Remotion 组件。默认不要求用户先选风格；只有操作者明确要求主题、品牌或参考片时才覆盖默认设置。

| 维度 | 作用 | 规范来源 |
|---|---|---|
| visualTheme / styleMode | 全片字体、构图与图形质感；styleMode 是兼容字段，不决定逐镜动作 | 本文 |
| palette | 全片背景、文字、图形、字幕与封面的颜色 | [色板.md](./色板.md) |
| typography | 按文字语义角色固定字号 | [typography.md](./typography.md) |
| visualGrammar | 知识点的表达方法：示意图、图表、时间线、对照、结构拆解等 | 本文 |
| shotLang | 单镜主体类型与运镜倾向 | [镜头语言.md](./镜头语言.md) |
| motionPlan | 知识关系、主辅动效模式与组件执行意图 | [motion-system.md](./motion-system.md) |

## 默认设置与唯一来源

新项目默认 `styleMode: "vox-light"`，使用 `色板.md` 中的 `paper` 暖浅底，不再默认 `tech-mint` 深空、星空或渐变。所有背景、卡片、字幕、图例、连线、片尾遮罩与封面引用同一色板。不得在本文或组件中维护另一套默认 HEX 值。

第 4 步以 [visual-planning-workflow.md](./visual-planning-workflow.md) 为唯一执行入口，按 4A–4D 分开决策。色板和固定字号按相关表格全片一次读取，镜头/动效只查已选条目，不要求同时全文加载所有规范；第 5 步记录到 `制作过程/视频制作方案.json` 与 `制作过程/视频方案审阅稿.md`，第 7 步按实际所用规范检查并实现 `palette.ts`、`typography.ts`，同步 `scenes.json`。按需读取不豁免实际色值、文字角色或安全区约束。

若旧 styleMode 的示例色值与批准色板冲突，以批准方案为准，所有组件统一迁移，不允许部分组件继续沿用旧色。深浅底切换必须整片统一并重新 Review；不得因选择 styleMode 就让每镜使用同一运镜。

字体通过review-v1-fixed完整样式和显式fontRole绑定，执行值唯一来源 `assets/typography.json`，规则见typography.md。顶部标题不随W1改为手写，字幕显式文楷；知识胶囊44/900、节点/结论44/800。特殊钩子96和符号140用独立角色，不任意倍乘普通标题。封面与视频仍为独立字号体系。

## 自动视觉规划决策

1. 机制、过程、空间关系：科学示意图、剖面、路径、流场、状态变化。
2. 数字、趋势、比较：代码绘制图表、时间线、对照；精确数字禁止用生图模型生成。
3. 历史、演变、人物关系：时间线、地图、档案素材与关系图；历史图片记录来源，不用生成图冒充史料。
4. 抽象概念、理论结构：结构图、层级图、类比示意；明确类比与真实机制的边界。
5. 观点、论证、决策：论点—证据—反例—结论结构、对照表与重点文字。
6. 阅读、人文、成长：手绘笔记、纸张拼贴、编辑式排版，装饰不能削弱论证。
7. 多种方法都可行时，优先准确表达、复用已有组件、减少新增素材。

全片统一的是视觉身份，不是表达方法。同一色板可依次呈现因果图、对照图、时间线；表达变化不能导致换一套颜色。

## styleMode 兼容规则

| styleMode | 表现特征 | 新项目配色与约束 |
|---|---|---|
| vox-light（默认） | 浅底编辑式图表与知识解释 | 默认 paper；深色文字、平涂、无发光、遮罩同 bg |
| vox | 深色图表驱动论证 | 操作者要求深底时从色板.md 选择 ink / navy；图表准确、标注随旁白 |
| kurzgesagt | 扁平矢量概念图形 | 使用批准色板，可浅可深；一镜一概念，纯色块、无无意义粒子 |
| doodle-note | 手绘线稿、纸张笔记 | paper / wood / snow 等批准浅底；线条 ink，强调 accent |
| tech-mint | 科技界面、节点、尺度场景 | 新项目须明确要求，使用批准色板平涂，不默认星空、渐变或发光 |

旧项目已批准的深空主题可保留原背景实现，不主动改写。`code-templates.md` 中旧 StarfieldDrift、渐变和硬编码色值只用于对应旧项目兼容，不是新项目默认。新组件必须先将颜色与字号迁移到全局 token。

### vox / vox-light：图表驱动解释

- 图表是主体，曲线、地图、柱状按旁白逐步展示；标注线、箭头、重点文字来自 accent / accent2。
- 叙事围绕问题、背景、证据推进与判断，不只是数据轮播。
- 第 7 步先使用预估时长，第 8 步按真实配音同步标注节奏，不能提前把时长写死。
- 浅底字幕使用 ink；遮罩使用 bg，不黑场压暗；层级靠描边、surface、字重，不靠发光。
- 警示颜色仅用于真实警示，通过语义映射取色，不能为了“醒目”新增红色或霓虹。
- 禁花哨转场、装饰粒子、玻璃拟态，以及用生图模型画精确数据。

### kurzgesagt：扁平矢量

- 一镜一个核心概念，纯色块、圆角图形、极简标注；撞色只从批准色板中取。
- 无渐变、玻璃拟态、发光或无意义粒子。阴影不作为默认质感。
- 平移、缩放、依次揭示服务语义；不默认每个元素 spring 回弹，具体模式见 motion-system.md。
- 不挂 StarfieldDrift；底色用 palette.bg，不能另选一组深底 HEX。

### doodle-note：手绘笔记

- 背景 palette.bg，笔色 palette.ink，线宽 3–4px，圆头圆角；强调使用 palette.accent。
- path 端点轻微抖动、中段弓形偏移，伪随机固定 seed；小圆抖动随半径收敛。
- pathLength 与 strokeDashoffset 实现逐笔绘制，按语义错峰，不用擦除或滑动冒充绘制。
- 画完后可保留极缓纸面呼吸；不能让长镜完全冻结，也不能以持续运镜干扰读字。
- 优先代码手绘 SVG，复杂有机轮廓用平滑闭合形；隐喻读不出语义就换方案。
- 字体先探测中文字符可用性；字号一律按 typography.md，不另设手绘模式的小字号。
- 默认不添加顶部常驻栏目标题；只有操作者明确要求时才启用 section / series 角色，仍遵守安全区。

## AI slop 红线

新项目避免蓝紫渐变、紫色星空、玻璃拟态、漂浮装饰粒子、无意义光晕、赛博霓虹堆砌。生图负向约束：`flat design, solid color blocks, no gradient, no glow, no particles, no glassmorphism`。

真实机制需要粒子或流动时，可使用批准的 FLOW_FIELD 等有明确方向、路径和证据依据的动效；这不是装饰粒子例外。组件依旧帧驱动、确定性，颜色取自色板。

## 版面安全区

- 画面 1080×1920，顶部 0–150px 为平台留白区，Effect 内容从 top:150 起，左右留白至少 40px。
- 主视觉使用SceneCanvas局部1000×1210，原点为屏幕(40,150)。position bounds计算所有SVG子偏移、半径、描边、padding、缩放最大值与字形，局部底缘不超过1210；不要因外层height1210就以为子SVG top90和circle cy1150自动安全。字号升级后重新布局，不能缩字规避。配图objectFit:contain。
- 字幕容器 top:1440、左右至少 56px、bottom 至少 250px；具体字形边界须在第 10 步人工检查，不与 Effect 重叠。
- y=1700–1920 不放内容；背景纹理等无文字装饰层可全幅，但不能盖住内容。
- 默认禁视频底部进度条、顶部 eyebrow、底部品牌带、英文 chip/pill 短标。

## Effect 组件规范

- Composition 统一 palette.bg 打底，Effect 可透明继承或使用同一 palette.bg；浅底不挂 StarfieldDrift。
- 禁 3D rotateY 翻页，使用 2D 平移、缩放、淡入；时间参数使用绝对帧数。
- 字号由 typography.ts 的文字角色决定，不自动缩字，不整体缩放文字容器规避规范。
- prop 接口 `{ frame, fps, durationInFrames, scene }` 完整解构，不丢 scene。
- 容器与子内容共用同一个 opacity 入场变量，避免先出现空底轨或空卡片。
- 每镜一个独立 `{sceneId}-{EffectName}.tsx`；可复用底层参数化组件，但不能多镜共用一个顶层 Effect 文件。
- 长知识镜不能只有标题；旁白中的关键名词、数值、对比、流程、枚举与因果关系均应落实到画面。
- 相邻镜共享视觉锚点并有意改变构图或信息层级；过渡镜画出上镜收束与下镜雏形，不只显示一句标题。

## 字幕系统

- 固定 typography.subtitle，即 70px；默认纯中文，单行不超过 13 个视觉字符，中文计 1，英文与数字计 0.55。
- 每次一行，旧行淡出、间隙、新行淡入；字幕不使用 nowrap，不动态缩小字号。
- FADE_IN=10 帧、FADE_OUT=10 帧、GAP=8 帧；短区间需校验不能溢出 segEnd。
- 三级切割：强标点 → 逗号/顿号 → 字符数截断；过滤纯标点片段，显示时去尾标点。
- 单段 TTS 时按汉字数分配，分段 TTS 时使用真实 startSec；具体选择与核验见 draft-review-workflow.md、production-workflow.md。
- 有 tailSec 时字幕只在有声区间分配，静场不摊字幕时间。

## 封面规范

- 第 9 步先只输出 V1、V2 两版 SVG，1080×1440；问句大标题加格式化核心内容，不能只有文字段落。交付后等待封面 Review，明确确认当前 SVG 后才转换获批版本为 PNG；修改 SVG 后旧确认失效。
- 两版均使用批准色板，V2 背景与视频首帧一致。
- 封面字号使用独立模板，不把视频 title token 直接用作封面主标题。
- 标题.txt 问句不超过 16 字，描述.txt 不超过 1000 字，结尾带话题标签。

## narration 与 subtitle

两者语义一致，仅允许为发音进行中文等价替换。subtitle 可保留英文术语；narration 使用中文读音友好的等价词，不能以发音修复为由丢掉论点。TTS 读取 narration，兼容回退为 subtitle。

## 验收边界

第 7–9 步做非渲染静态检查与类型检查。第 10 步由人工启动 Remotion，核对开头、最高信息密度镜、关键转折和结尾的关键帧与正常速度片段；不自动渲染，不用源码检查声称视觉已通过。详细检查与返工路由见 render-quality-check.md。
